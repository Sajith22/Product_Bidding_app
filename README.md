# BidForge — Customer Auction Platform (Flutter)

A real‑time auction platform where users browse products, place bids, and get notified when they win.  
This is the **customer‑facing Flutter web & mobile app** — the admin side lives in two separate repositories.

## Architecture

```
┌─────────────────────┐          ┌──────────────────────┐
│   Flutter Web/Mobile │ ──────► │   Firebase Project   │
│   (Customer App)     │ direct  │  (biddingapp-2b035)  │
│   - Browse auctions  │ Firestore│  - Auth             │
│   - Place bids       │ listeners│  - Firestore DB     │
│   - View results     │         │  - FCM               │
└─────────────────────┘          └──────────┬────────────┘
                                           │
┌─────────────────────┐                    │
│  React Admin Web     │ ──────► HTTP API  │
│  (bidforge-admin-web)│                    │
└─────────┬────────────┘                    │
          │                                 │
          ▼                                 │
┌─────────────────────────────────────────┴─┐
│         NestJS Backend (bidforge-admin-api) │
│  - FirebaseAuthGuard (custom claims)        │
│  - Products CRUD                            │
│  - Auto‑close auctions (cron job)           │
│  - Push notifications (FCM)                 │
└─────────────────────────────────────────────┘
```


**Why three repos?** The customer app, the admin interface, and the trusted backend deploy and scale differently, and more importantly — they have different trust levels. The customer APK contains no admin logic.

## Features

### Customer App (this repo)
- Browse Live / Upcoming / Ended auctions with real‑time bid updates
- Place bids via Firestore transactions (race‑condition safe)
- Live countdown timers, leading/outbid indicators
- Win screen with price breakdown
- In‑app notification bell backed by Firestore
- Push notifications via Firebase Cloud Messaging
- Role‑based auth (customer role only)

## Setup

### Prerequisites

- Flutter >= 3.0.0
- Firebase project (`biddingapp-2b035`)

### 1. Clone & install

```bash
git clone https://github.com/Sajith22/bidding_app.git
cd bidding_app
flutter pub get

```

### 2. Configure Firebase
```bash
flutterfire configure
```
This generates lib/firebase_options.dart (never commit this file).

### 3. Run locally
```bash
flutter run -d chrome   # Web
flutter run -d <device> # Mobile
```
📦 Deployment (Firebase Hosting)
```bash
flutter build web --release
firebase deploy --only hosting
```
Live URL: https://biddingapp-2b035.web.app

## 🔁 CI/CD
On every push to the main (or your default branch), a GitHub Actions workflow automatically builds and deploys the web app to Firebase Hosting.
Workflow file: .github/workflows/firebase-hosting.yml
Requires FIREBASE_TOKEN secret in GitHub.
